# 墨桥 MoBridge

> **墨坊造器，墨桥通路。**
> 把第三方免费模型接入你的 AI 客户端 —— 自动检测真实可用性,勾选要用的模型,一键写入配置。

墨桥在本机后台运行一个隔离的模型服务,向各路免费模型逐个发极小请求、测出**真实可用性与耗时**,
再把可用的模型写入你的客户端配置——只动自己写入的条目,不碰其它工具的配置。

## 能不能用

| | 支持 |
| --- | --- |
| 模型来源 | OpenCode 免费模型 · AtomCode(CodingPlan) · 日日新(需自己的 API Key) |
| 写入目标 | WorkBuddy · DSH · 墨坊 · Qoder · Trae |
| 系统 | Windows 10/11 x64(安装版或便携版,无需安装 Node) |
| 费用 | 免费;检测只发极小请求,不消耗对话额度 |

## 快速开始

1. 到 [Releases](https://github.com/jzaini/MoBridge/releases) 下载 `墨桥 Setup x.x.x.exe`,双击安装(可自选目录)
2. 启动后按左侧步骤:连接服务 → 检测模型 → 勾选要用的
3. 点「写入配置」——到你的客户端里选这些模型,开始使用

版本变更明细见 [更新日志](docs/CHANGELOG.md)(应用内 设置 → 更新日志 也可查看)。

## 功能

| 接入线 | 能力 |
| --- | --- |
| OpenCode | 免费模型目录、逐模型真实检测(可用性/耗时/失败原因中文说明)、勾选写入、系统代理 |
| AtomCode | 安装引导、登录、套餐额度、实时模型目录、独立转发口 |
| 日日新 | API Key 本机保存、逐模型探测、直连写入(不经转发口) |

- 检测结果**缓存复用**(成功 6 小时/失败 1 小时/瞬时故障 10 分钟),不重复消耗免费额度
- 写入条目带 owner 标记,多个工具共写一份配置也互不擦除
- 应用退出不动客户端配置;卸载/移除只清理墨桥写入的条目

## 架构

Electron 壳层(主进程/preload/渲染层)+ 纯 Node 服务层(由主进程 fork,免装 Node)。
渲染层与主进程之间只有状态广播与白名单动作两条通道;API Key 与配置全部只存本机。

```
客户端(WorkBuddy / DSH / Qoder / …)
   │  OpenAI 兼容接口(127.0.0.1:31280,AtomCode 口 31282)
   ▼
墨桥服务层(鉴权 → 模型名还原 → 判定缓存 → OpenCode / AtomCode / 日日新)
   │                              │
   ▼                              ▼
上游免费模型                  写入目标配置(只动自己的条目)
```

```bash
npm run build:win  # NSIS 安装包(发版)
```
